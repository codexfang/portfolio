# Jason Fang — Portfolio

Personal portfolio showcasing projects, experience, and collaborations across software engineering, AI/ML, and design.

Built with **React**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## Sections

- **About** — Background & focus
- **Experience** — Career timeline
- **Projects** — Selected work
- **Collaborations** — Trusted by
- **Contact** — Get in touch

## Development

```bash
npm install
npm run dev
```
